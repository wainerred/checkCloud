# Selectel Server Inventory — Инструкция

## Установка

```bash
pip install requests openpyxl
```

---

## Шаг 1 — Создать сервисного пользователя

1. Войдите на [my.selectel.ru](https://my.selectel.ru)
2. Верхнее меню → **Аккаунт** → **Пользователи** → вкладка **Сервисные пользователи**
3. Нажмите **Создать пользователя**, задайте имя и пароль
4. Назначьте роль **Администратор** (или хотя бы доступ к нужным проектам)
5. Сохраните **имя пользователя** и **пароль**

**Номер аккаунта** виден в правом верхнем углу панели управления (число, например `1234567`).

---

## Шаг 2 — Запустить скрипт

```bash
python selectel_servers.py \
  --username ИМЯ_СЕРВИСНОГО_ПОЛЬЗОВАТЕЛЯ \
  --account  НОМЕР_АККАУНТА \
  --password ПАРОЛЬ
```

Или через переменные окружения:

```bash
export SEL_USERNAME="svk-user-abc"
export SEL_ACCOUNT="1234567"
export SEL_PASSWORD="my_secret_password"

python selectel_servers.py
```

---

## Что получится

Скрипт создаёт два файла с временной меткой:

```
selectel_servers_20250428_143022.json
selectel_servers_20250428_143022.xlsx
```

**Excel** — два листа:
- `Выделенные серверы`
- `Облачные серверы`

Столбцы: `Имя | IP | Конфигурация | Регион | ОС | Дата оплаты`

> Облачные серверы оплачиваются **почасово**, поэтому в поле "Дата оплаты" указано "почасовой".

---

## Как работает авторизация (Selectel Keystone IAM)

```
Сервисный пользователь + пароль
              ↓
  POST cloud.api.selcloud.ru/identity/v3/auth/tokens
              ↓
  X-Subject-Token  (живёт 24 часа)
              ↓
  Выделенные серверы → X-Auth-Token в заголовке
  Облачные серверы   → project-scoped token на каждый проект
```

## Troubleshooting

| Ошибка | Решение |
|--------|---------|
| `401 Unauthorized` | Неверный логин/пароль или номер аккаунта |
| `403 Forbidden` | Пользователь не имеет нужных прав |
| `Облачные серверы: 0` | Нет проектов или пользователь не добавлен в проекты |
| `No Nova endpoint in catalog` | Проект пуст или сервисный пользователь без доступа к проекту |
